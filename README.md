## Featured projects

### [signalbase](https://github.com/nyxashu25/signalbase) — DataPit, B2B sales intelligence platform
An Apollo/Slintel-style platform: searchable contact and company database, credit-gated email reveal, lists, and automated outreach sequences. Built with Node.js, Express, React, Vite, PostgreSQL (Prisma) and Elasticsearch, and it ships with a Chrome extension.

### [auto-scrape-verify-buy](https://github.com/nyxashu25/auto-scrape-verify-buy) — ExpiredDomains → SEMrush Authority Sorter
A Chrome extension that collects domains from ExpiredDomains.net, looks each one up on SEMrush, and sorts them by Authority Score. It also imports CSV lists and adds Dynadot checks.
